SCO LIDEX Source Build Notes
============================

SCO LIDEX is a Windows-only .NET WinForms application.

Requirements:
- Windows 10 or newer.
- .NET SDK matching the target framework in SCOLIDEX.csproj.
- Internet access for normal terrain runs, because elevation data is requested
  from USGS services at runtime.

Build:
  dotnet build SCOLIDEX.csproj -c Release

Publish self-contained Win x64:
  dotnet publish SCOLIDEX.csproj -c Release -r win-x64 --self-contained true -o dist\SCOLIDEX-win-x64

Distribution layout:
  AddShortcutDesktop.cmd
  README.md
  README.txt
  SCOLIDEX-win-x64\
  docs\

The docs folder is tracked in source and must be copied into every packaged
distribution. Keep the root README files and docs copies synchronized before
publishing a release.
