Ver 1.200: SCO LIDEX is a modern cloud-based terrain-building utility for Open Rails route builders with US high-resolution and low-resolution global coverage. It creates normal 8m terrain tiles, optional TSRE-style distant mountains, and optional 4096x4096 TSRE-compatible F3 map overlays from anonymous Geofabrik OpenStreetMap extracts. The source sequence is USGS 1m LIDAR, USGS Original Product Resolution shown as 5m~, USGS/NED 1/3 arc-second shown as 10m, then key-free Copernicus DEM GLO-30 Public shown as 30m (global) for unresolved coverage. Copernicus is a low-resolution DSM that may include vegetation, buildings, and infrastructure. Normal terrain is sampled using the ORTS 256-post raw height grid at true 8m post spacing. Standard-projection routes include the calibrated 16m east and 16m south TSRE map compatibility correction. Map vertices use that same terrain coordinate path; each map run directly replaces the matching terrain_maps X*10000+Y PNG while leaving terrain materials, UVs, TERRTEX files, and Distant Mountain tiles unchanged. Geofabrik downloads are resumable and cached, and selected-route geometry is loaded once and retained while two map images are rendered concurrently. No API key, external route editor, or MSTS runtime is required. The tool can process existing route tiles or select coverage from a tile list, marker file, KML file, or track database. It includes read-only Scan, Scan Override, Help, Append and Overwrite modes, meter-based geo bias calibration, run logging, Distant Mountain generation, automatic retry marking, and paste-ready failed-tile lists. SCO LIDEX requires Windows 10 or newer and internet access while processing. Always back up routes before use. Issued under GNU GPL v3 or later. By Scott Brunner, Beast of Burden.
