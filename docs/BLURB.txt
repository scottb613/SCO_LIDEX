Ver 1.100: SCO LIDEX is a modern cloud based terrain-building utility for Open Rails route builders - US coverage only. It creates route terrain from USGS 1m LIDAR elevation services, including normal 8m terrain tiles and optional TSRE-style distant mountain tiles. Normal terrain is sampled using the ORTS 256-post raw height grid at true 8m post spacing for improved route/map overlay alignment. Standard-projection routes now include a calibrated 16m east and 16m south TSRE map compatibility correction. When 1m coverage is missing, normal route tiles can fall back through USGS Original Product Resolution DEM shown as 5m~, and then USGS/NED 1/3 arc-second elevation shown as 10m; distant mountain tiles use 10m elevation. The tool can process existing route tiles or select coverage from a tile list, marker file, KML file, or track database. It includes a read-only Scan step before Run, optional Scan Override, a formatted read-only Help viewer, Append and Overwrite modes, meter-based geo bias calibration, run logging, DEMEX-to-TSRE distant mountain replacement, automatic Append retry marking for failed normal tiles, and optional paste-ready failed-tile lists for targeted retry runs. SCO LIDEX is intended for Windows 10 or newer and requires internet access while processing. Always back up routes before use. Issued under the GNU General Public License, version 3 or newer.
