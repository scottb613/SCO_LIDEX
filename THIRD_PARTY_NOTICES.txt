OpenStreetMap and Geofabrik
---------------------------
Create Map Tiles uses OpenStreetMap data supplied as regional extracts by
Geofabrik GmbH. OpenStreetMap data is copyright OpenStreetMap contributors and
is available under the Open Database License (ODbL).
https://www.openstreetmap.org/copyright
https://download.geofabrik.de/

SCO LIDEX uses Geofabrik downloads for bulk access and does not bulk-download
from the public OpenStreetMap editing API or standard map-tile servers.

Open Rails / MSTS / TSRE route formats
--------------------------------------
SCO LIDEX writes files compatible with Open Rails / MSTS route terrain and
TSRE-style terrain workflows. SCO LIDEX is not an official Open Rails or TSRE
project.

USGS elevation services
-----------------------
SCO LIDEX requests elevation products from USGS services. Users are responsible
for complying with any applicable USGS service terms and availability limits.

Copernicus DEM GLO-30 Public
----------------------------
SCO LIDEX can read Copernicus DEM GLO-30 Public Cloud Optimized GeoTIFFs from
the Registry of Open Data on AWS without an account or API key. Copernicus DEM
is a Digital Surface Model representing the Earth's surface, including
buildings, infrastructure, and vegetation.

Copernicus Digital Elevation Model (DEM) was accessed from:
https://registry.opendata.aws/copernicus-dem/

Terrain produced by SCO LIDEX adapts the source data. Required source notice:

and Space GmbH 2014-2018 provided under COPERNICUS by the European Union and
ESA; all rights reserved.
