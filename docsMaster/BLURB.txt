Ver 1.300: SCO LIDEX is a modern cloud-based terrain-building utility for Open Rails route builders with US high-resolution and low-resolution global coverage. Route, Distant Mountain, and OSM/map creation default on. Normal terrain is locked to 8m unless Enable HD Mesh Tiles unlocks the HD Test - 4m output. OSM map overlays default to 2048x2048, with optional 4096x4096 HD output, using anonymous Geofabrik extracts. Normal terrain uses USGS 1m LIDAR, USGS Original Product Resolution shown as 5m~, USGS/NED 1/3 arc-second shown as 10m, then key-free Copernicus DEM GLO-30 Public shown as 30m (global) for unresolved posts. When route terrain is selected, read-only Scan flags mixed terrain resolution and Run performs approved conversion; terrain resolution is ignored when route terrain is not selected. Distant Mountains use Copernicus GLO-30 exclusively, resampled onto the 128m low-terrain grid. Copernicus is a low-resolution DSM that may include vegetation, buildings, and infrastructure. Standard-projection routes include the calibrated 11m east and 16m south TSRE map compatibility correction. Map vertices use that same terrain coordinate path; each map run replaces matching terrain_maps X*10000+Y PNGs while leaving terrain materials, UVs, TERRTEX files, Distant Mountain tiles, and unrelated map PNGs unchanged. LIDEX checks the selected route's OSM cache first, then other registered route caches, uses covering extracts directly without copying, and downloads into the selected route only when no cache covers it. No large PBF cache is stored in AppData. Geofabrik downloads are resumable, and selected-route geometry is loaded once and retained while two map images are rendered concurrently. No API key, external route editor, or MSTS runtime is required. The tool can process existing route tiles or select coverage from a tile list, marker file, KML file, or track database. It includes read-only Scan, Scan Override, in-app Help, concise option tooltips, Append and Overwrite modes, meter-based geo bias calibration, run logging, automatic retry marking, and paste-ready failed-tile lists. SCO LIDEX requires Windows 10 or newer and internet access when an uncached source is needed. Always back up routes before use. Issued under GNU GPL v3 or later. By Scott Brunner, Beast of Burden.
