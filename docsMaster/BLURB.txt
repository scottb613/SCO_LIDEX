Ver 1.401 HOTFIX: SCO LIDEX now preserves fractional-metre DEM elevations through normal 8m, HD Test 4m, and Distant Mountain generation instead of rounding every source sample to a whole metre. This removes the terrain terracing introduced by v1.400 while retaining seamless tile edges and the established external _y.raw format. The release also gives tree rows the exact natural=wood woodland color, presents Scan and Run logs in clearer human-readable sections without losing troubleshooting detail, and standardizes source and executable ownership/licensing metadata. HD Test 4m remains an evaluation format; some Open Rails unstable builds still calculate its lighting normals with an 8m spacing assumption, which can create false shading even when the terrain geometry is correct. SCO LIDEX uses USGS 1m, Original Product Resolution 5m~, NED 10m, and key-free Copernicus GLO-30 fallback for normal terrain; Distant Mountains use Copernicus GLO-30 exclusively. It supports route tiles, text lists, marker files, KML files, and track databases; creates optional OSM/PolyVeg map data from anonymous Geofabrik extracts; provides read-only Scan, Append and Overwrite modes, terrain-resolution conversion, bounded rolling seam processing, retry reporting, and automatic cache reuse. Windows 10 or newer and internet access are required when an uncached source is needed. Always back up routes before use. Issued under GNU GPL v3 or later. By Scott Brunner, Beast of Burden.
