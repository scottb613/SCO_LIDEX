SCO LIDEX Changelog
===================

v1.200
------
- Changed Scan from all-or-nothing service gating to a per-source capability
  plan covering USGS 1m, 5m~, 10m, Copernicus 30m global, and Geofabrik maps.
- Added a final source-status and Run-plan summary. Individual outages remain
  clearly marked FAILED, while a usable fallback produces PASSED WITH WARNINGS
  and enables Run for the viable selected stages.
- Source results use separate Data, Source, and PASSED/FAILED lines for easier
  reading in both Scan and Run logs.
- Added explicit USGS detail in Scan and Run so SERVICE ONLINE / NO ROUTE
  COVERAGE cannot be mistaken for a service outage.
- A malformed USGS product response no longer prevents Copernicus fallback.
- Corrected GUI status parsing so Data Source `Status: FAILED` lines remain
  informational and cannot suppress the final operation-complete state.
- Added explicit terrain, Distant Mountain, and OSM/map completion statuses.
- Moved downloaded Geofabrik PBF extracts into each route's
  OpenStreetMap\geofabrik folder and added a portable osm-cache.json manifest.
- Added verified migration of matching legacy AppData PBF and partial-download
  data so existing large downloads are reused rather than fetched again.
- Added an AppData cache-registry-v1.json index for discovering route-local
  caches while keeping the route manifest authoritative.
- Replaced whole-cache exit deletion with unchecked per-cache selections for
  regional extracts and incomplete downloads. The small shared Geofabrik index
  remains internal application data and is never offered for deletion.
- Purge Selected with no checked cache now plays the failure buzz, deletes
  nothing, and keeps the exit dialog open.
- Classified generated terrain_maps PNG files as permanent route output; cache
  cleanup never lists, deletes, or removes those map images or their folder.
- Sources that fail or report no representative coverage during Scan are not
  polled during the following Run. Copernicus can carry global terrain and DM
  work independently of USGS availability.
- A Geofabrik outage no longer blocks terrain or DM. Map generation uses a
  usable cached regional index/PBF without polling the failed service, or skips
  only the map stage when no valid cache exists.
- Added immediate SCANNING status and a one-second working indicator that cycles
  active statuses through zero, one, two, and three real bullets on each side.
  Completion, failure, error, abort, and ready states remain fixed.
- Create Map Tiles writes directly to TSRE's F3
  `terrain_maps/<X*10000+Y>.png` overlay cache. Matching PNGs are overwritten;
  no map ACE is created and terrain `.t` materials/UVs remain unchanged.
- Corrected F3 cache naming for the route coordinate convention: TSRE map Y is
  the negative of terrain Z, so the filename hash is `X*10000-Z` in LIDEX.
- Added non-overlapping interface audio for button presses, checkbox/radio
  selections, ordinary status changes, successful Scan/Run completion, and
  failure/error/abort indications.
- Assigned SCOprogress to ordinary status messages and SCOsuccess to successful
  Scan and Run completion.
  All supplied WAV assets are retained in source and distribution output.
- Expanded the center message panel to report Scan, terrain-source, DM, OSM
  download/processing/rendering, completion, failure, and abort stages using one
  consistent color. Terrain and DM failures now finish their current batch and
  gate all later production stages so Append/correction can occur first.
- Added an isolated experimental 4m normal-terrain test path: KML can create the
  full route footprint, every normal tile is generated as a 512x512 grid, shared
  edges/corners are merged, and optional map textures run afterward. DM remains
  disabled and the established 8m writer is unchanged.
- Deactivated 4m export after the initial test build while retaining the complete
  implementation behind one internal feature switch. The GUI now remains fixed
  to Normal - 8m output.
- Restored the Route Path Browse button with the Windows folder-selection dialog.
- Added a clearly labeled Recent menu backed by
  %LocalAppData%\SCOLIDEX\route-history.json, retaining the five most recent valid route
  folders and automatically filtering missing or invalid entries.
- Kept the WinForms entry thread in STA mode so route autocomplete and the
  Windows folder-selection dialog initialize reliably.
- Uses a dedicated Recent button instead of a native ComboBox, improving
  contrast and avoiding re-entrant native drop-down behavior.
- Enabled Create Map Tiles with anonymous Geofabrik OpenStreetMap regional PBF
  extracts, resumable local caching, and read-only source/driver Scan checks.
- Added self-contained 4096x4096 TSRE ACE reference-texture writing without an
  external editor or MSTS tool.
- Uses the same corrected terrain projection for every OSM vertex and validates
  tile corners/center; the Austria acceptance route measured 0.000000 pixels.
- Added transactional temporary output and timestamped backups for replaced map
  ACE files.
- Loads selected-route PBF geometry once, retains it for the complete run, and
  renders two map textures concurrently without a geometry reload.
- Replaced the initial dark LIDEX map theme with a direct port of TSRE's OSM
  vector background, feature colors, road casings/widths, and drawing order.
- Corrected Geofabrik selection to require one extract that covers every
  selected terrain tile; multi-state routes now select the broader regional
  extract instead of the smallest extract containing only the route center.
- Treats genuinely featureless OSM tiles as valid TSRE background textures
  instead of aborting the map run.
- Matched TSRE's OSMFeatures layer priorities so water polygons render above
  overlapping residential, forest, and other land-use polygons.
- Preserves the complete OSM node stream while filtering finished geometry,
  allowing long river, lake, and forest multipolygon relations to remain
  complete when their remote vertices extend beyond the selected route area.
- Rebuilds TSRE's normal terrain database index whenever Marker, KML, Track
  Database, or text-list selection creates route tiles, ensuring newly created
  .t, _y.raw, and world-file sets appear as editable base terrain in TSRE.
- Added anonymous Copernicus DEM GLO-30 Public fallback coverage after the
  existing USGS 1m, 5m~, and 10m sources for normal and Distant Mountain
  terrain.
- Added separate 30m (global) status counters, low-resolution mode indicator,
  source logging, scan validation, and data-read accounting.
- Increased the window height to accommodate the new status row without
  reducing the running-log area.
- Moved Copernicus tile discovery and COG reading into Program.Copernicus.cs.
- Separated selection, terrain, Distant Mountain, projection, Copernicus, and
  map generation into major partial-class components without changing the GUI.
- Moved map-cache size reporting to a unified exit dialog with Keep Cache,
  Purge Cache, and Cancel Exit choices for both the Exit button and window X.

v1.100
------
- Corrected standard-projection terrain placement by 16 meters east and
  16 meters south to match the TSRE map-coordinate convention observed
  consistently across multiple routes.
- Applied the correction at geographic sampling time to both normal terrain
  and Distant Mountain generation, preserving seamless tile transitions.
- Left route-specific TsreGeoProjection mapping unchanged.
- Added GEOMETRY_PLACEMENT_CORRECTION.txt with the source comparison and
  technical explanation.
- Aligned the Windows executable file and product metadata with version 1.100.
- Restored a tracked and distributed docs folder, added a GitHub Markdown
  README, and expanded the v1.000/v1.100 release highlights.

v1.000
------
- Finalized first public release version numbering.
- Help viewer copy/example text now uses the same standard dark text color
  instead of the brown accent color.
- Added single-instance GUI protection so a second launch does not start a
  second SCO LIDEX session.
- Tightened release documentation and third-party notice wording.

v0.117
------
- Updated retry documentation: Append is now documented as the primary recovery
  path for retryable failed normal terrain tiles.
- Clarified that SCOLIDEXTiles.txt paste-ready lists are optional targeted
  retries, not the first required recovery step.

v0.116
------
- Standardized status tally colors so normal counts use the same neutral color.
- Failure counts still use the failure color.

v0.115
------
- Restored publishing of bundled generated-tiles clean terrain templates.
- Scan now checks Clean Tile Wipe template availability before enabling Run,
  so a missing clean template is caught before any route files are written.
- This fixes Clean Tile Wipe runs failing mid-route with "could not find a
  clean terrain .t template".

v0.114
------
- Changed normal route terrain DEM sampling to use the ORTS 256-post raw grid
  at true 8m post spacing.
- Normal _y.raw terrain now samples a 2040m stored post span inside the nominal
  2048m tile instead of stretching 256 posts across the full tile footprint.
- This should improve terrain alignment with route/map overlays while keeping
  existing seam merge behavior intact.
- Updated README, INSTRUCTIONS/Help, BLURB, and package version text.
